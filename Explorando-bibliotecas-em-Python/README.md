# Explorando bibliotecas em Python

Exemplos publicados para apresentar bibliotecas Python em tarefas práticas, de visualização de dados a manipulação de imagens.

| Projeto | O que demonstra | Biblioteca principal |
| --- | --- | --- |
| [Gráficos com Seaborn](basic_commands_seaborn/README.md) | Dispersão, linhas, barras, regressão, caixas e correlação | Seaborn e pandas |
| [Plotagem de grafos](graph_plot/README.md) | Desenho de grafos a partir de listas de adjacência | igraph |
| [Imagens em tons de cinza](greyscale_images/README.md) | Conversão e gravação de uma imagem | Pillow |
| [Widgets no Jupyter](ipywidgets_jupyter_notebook/README.md) | Filtros e gráficos controlados por widgets | ipywidgets e Plotly |
| [Tradutor de frases](sentence_translator/README.md) | Tradução de texto digitado no terminal | googletrans |
| [Tabelas no terminal](tables_in_terminal/README.md) | Formatação, alinhamento e ordenação de tabelas | PrettyTable |
| [Áudio do YouTube em MP3](yt_music_python/README.md) | Download de áudio e conversão para MP3 | pytube e MoviePy |

Cada projeto tem suas próprias dependências. Consulte o README correspondente antes de executar e mantenha o terminal na pasta do exemplo para que os caminhos de arquivos funcionem.
