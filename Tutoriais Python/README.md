# Tutoriais Python

Notebooks de tutoriais com explicações e exemplos progressivos: fundamentos de Python, chamadas a modelos de linguagem, análise de dados com agentes e integração com MetaTrader 5.

| Projeto | Conteúdo |
| --- | --- |
| [Laços e iteração](All%20La%C3%A7os%20For/README.md) | `for`, `while`, pandas e concorrência com threads |
| [Como usar a API do ChatGPT](Como%20usar%20API%20Chat%20GPT/README.md) | Função para enviar mensagens à API da OpenAI e ler a resposta |
| [Engenharia de prompt em LLMs](Engenharia%20de%20Prompt%20em%20LLMs/README.md) | Classificação de sentimentos e extração de uma resposta delimitada por tags |
| [Pandas com LLM](Pandas%20com%20LLM/README.md) | Agente LangChain que executa Python sobre um DataFrame |
| [Guardrail para o Pandas LLM](Guardrail%20para%20o%20Pandas%20LLM/README.md) | Filtro de padrões no código enviado à ferramenta Python do agente |
| [MetaTrader 5 com Python](Metatrader5%20com%20Python/README.md) | Coleta de preços e backtest de uma estratégia com Bandas de Bollinger |

Abra cada notebook a partir da própria pasta e execute as células em ordem. Os exemplos com LLM exigem configuração de credencial; o de MetaTrader exige o terminal e acesso aos dados dos ativos. As dependências e limitações estão documentadas em cada projeto.
